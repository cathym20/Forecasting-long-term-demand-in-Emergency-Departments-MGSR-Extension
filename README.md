# Forecasting-long-term-demand-in-Emergency-Departments-MGSR-Extension

# Multi-Granular Forecasting of Emergency Department Demand

Replication and post-2022 extension of the Multi-Granular Stacked Regression (MGSR)
model proposed by James, Wood and Denholm (2023).

Author: Cathy Mariam Vijay
MSc Data Science dissertation, University of Bristol, 2025.

## Overview

This project reproduces the MGSR model on its original 2018-2019 CCG level data, then extends it into the post-2022 period at Sub-ICB Location level using Hospital Episode Statistics emergency admissions as the target, QOF chronic disease prevalence indicators from OHID Fingertips as the population health signal, and tuned Gradient Boosting learners instead of the paper's Random Forests.

The full dissertation is included as `dissertation.pdf`.

## Requirements

Python 3.9 or later. Dependencies are managed with [uv](https://docs.astral.sh/uv/).

```bash
uv sync
```

This reads `pyproject.toml`, resolves versions from `uv.lock`, and creates a
local `.venv/` with everything installed.

To launch Jupyter:

```bash
uv run jupyter lab
```

## Reproducing the analysis

Notebooks and scripts should be run in the order below. Each step consumes the
output of the previous.

**1. Fingertips features (extension only)**

```bash
uv run python scripts/fingertips_loading.py
```

Pulls QOF chronic disease prevalence indicators and IMD deprivation scores from
the OHID Fingertips API, aggregates to ICB level, and writes
`data/fingertips_icb_features.csv`. Requires network access.

**2. Health Index crosswalk (replication only)**

Run `notebooks/health_index_crosswalk.ipynb`. Uses the ONS LSOA-to-CCG-to-LAD
lookup to convert the LA-level Health Index into CCG-level scores for People,
Places and Lives, writes `data/health_index_ccg.csv`, and verifies that the
result correlates above 0.98 with the values in the authors' published dataset.

**3. Build the extension panel**

```bash
uv run python scripts/preprocessing_hes_final.py
```

Merges HES emergency admissions and secondary-care activity, ONS Sub-ICB
population estimates, NHS Digital Sub-ICB GP appointments, IUC 111 volumes,
and the Fingertips features from step 1. Writes `data/master_hes_2022_2025.csv`.

**4. Build the replication panel**

Run `notebooks/dataset_creation.ipynb`. Independently rebuilds the 2018--2019
CCG-level dataset from NHS Digital GP, NHS England AmbSYS and NHS 111 MDS
publications, ONS Mid-Year Population Estimates, and the CCG-level Health
Index from step 2. Writes `data/master_scaled_replicated.csv`.

**5. Chapter 3 results (replication)**

Run `notebooks/replication_modelling.ipynb`. Reproduces the MGSR on the
replicated 2018--2019 panel: Capacity Model, Population Health Model, and
Combined MGSR under 5-fold cross-validation with 5 repeats.

**6. Chapter 4 results (extension)**

Run `notebooks/extension_modelling_final.ipynb`. Reproduces all extension
results: eight-model comparison across eight feature sets, MGSR under both
capacity block definitions, GroupKFold validation by Sub-ICB and by ICB,
temporal holdout on 2024, and lagged-feature forecasting against SARIMA,
exponential smoothing, persistence and seasonal-naive baselines.

## Reproducibility notes

- All random seeds are fixed (`random_state=0` throughout). Repeated runs
  produce byte-identical output CSVs and notebook results.
- `uv.lock` pins exact package versions so the environment is stable across
  time and machines.
- The dissertation reports light differences (up to ~0.02 R²) in a few
  hyperparameter-tuning-dependent numbers between runs; the qualitative
  conclusions are unchanged. Randomised hyperparameter search uses
  `random_state=0` but sklearn tuning stability across versions is not
  perfectly guaranteed.
